# Lottery AI - 香港六合彩生肖多因子评分与回测系统 🚀

Lottery AI 是一款专为香港六合彩（最后一个特别号码所属生肖）设计的**量化投资分析与预测系统**。该项目摒弃了容易过拟合的深度学习和神经网络，完全立足于**统计学、概率论、马尔可夫链和均值回归**等经典的量化交易思想，建立了一套多因子动态评分预测框架。

最终目标：**每周推荐最值得关注的 5 个生肖（非预测号码/波色/单双）**。

---

## 📂 项目结构

```text
lottery-ai/
├── data/
│   └── history.csv            # 1~191期历史开奖数据 (period, number, zodiac)
├── config.py                  # 配置文件：生肖号码映射、波色定义、16大指标开关及评分权重
├── analysis.py                # 功能模块：数据完整性校验、多维度历史排行榜与衍生属性生成
├── backtest.py                # 核心引擎：Walk Forward (滚动前向验证) 回测、指标权重贪心调优
├── predict.py                 # 预测引擎：下一期推荐五星生肖、得分看板、推荐理由自动拼装
├── requirements.txt           # 项目运行依赖项 (pandas, numpy, scipy)
└── README.md                  # 项目使用与技术说明文档
```

## 🧠 核心量化算法（16大评分因子）

系统内置了 16 个完全透明的量化模型指标，每个指标均可独立开启或调整权重：

1. **历史热度 (`ENABLE_HISTORICAL_HEAT`)**：基于大数法则，计算全历史生肖出场频率。
2. **近10期热度 (`ENABLE_RECENT_HEAT_10`)**：捕捉超短期爆发现象。
3. **近20期热度 (`ENABLE_RECENT_HEAT_20`)**：捕捉中期热度惯性（Momentum）。
4. **近50期热度 (`ENABLE_RECENT_HEAT_50`)**：评估中长期趋势。
5. **遗漏值因子 (`ENABLE_MISSING_VALUE`)**：计算“当前遗漏期 / 历史平均间隔”以量化冷度。
6. **平均间隔因子 (`ENABLE_AVERAGE_INTERVAL`)**：频繁出现的生肖天然间隔短，赋予其优势权重。
7. **冷热平衡因子 (`ENABLE_COLD_HOT_BALANCE`)**：对比短期与历史出现概率，识别爆发拐点与连庄热度。
8. **一阶马尔可夫链 (`ENABLE_MARKOV`)**：构建 12×12 生肖状态转移矩阵，基于上期生肖计算状态转移概率。
9. **波色偏差纠偏 (`ENABLE_WAVE_REVERSION`)**：分析近15期红/蓝/绿波色的标准偏离度，当某种波色严重缺失时，对应该波色号码较多的生肖将获得“均值回归”加分。
10. **单双偏差纠偏 (`ENABLE_ODD_EVEN_REVERSION`)**：单双数大数偏差纠偏。
11. **大小偏差纠偏 (`ENABLE_SIZE_REVERSION`)**：大号/小号大数偏差纠偏。
12. **尾数偏差纠偏 (`ENABLE_TAIL_REVERSION`)**：0~9 尾数出现频率的动态偏离校正。
13. **连续出现惩罚 (`ENABLE_CONSECUTIVE_PENALTY`)**：在独立随机试验中，生肖连续连庄（特别号码连续出现相同生肖）概率较低（约 8.3%），对刚刚开出的生肖进行分数压制。
14. **极限遗漏回补 (`ENABLE_MAX_MISSING_RECOVERY`)**：当生肖遗漏值逼近或超过其历史最大遗漏值时，由于极限回归引力，赋予爆发性加分。
15. **周期性自相关 (`ENABLE_CYCLE_ANALYSIS`)**：计算 0-1 时间序列在 lags 1~15 处的自相关系数，寻找生肖各自的最强周期并在时点吻合时予以激活。
16. **相似历史窗口模式匹配 (`ENABLE_SIMILAR_WINDOW`)**：采用 $k$-最近邻（$k$-NN）思想，寻找历史中与近期生肖序列（如近2期 `[蛇-龙]`）完全相同的历史片段，统计其下一期开出分布。

## ⚙️ 自动指标调优（防过拟合贪心策略）

**“每增加一个评分指标，必须能够自动进行历史回测。如果命中率下降，自动关闭该指标。”**

系统在 `backtest.py` 中内置了自动调优程序：
1. 以“全部指标关闭（盲选）”作为最简基准（命中率约随机的 41.67%）。
2. 逐一开启 16 项量化因子，若在 **151期 ~ 191期** 的 Walk-Forward 滚动回测中**命中率有所提高**，则保留该开关为 `True`，否则自动置为 `False`。
3. 对筛选保留的优胜指标，通过多步长搜索微调权重。
4. 最终将最佳的因子组合与权重持久化保存到 `optimized_config.json`，实现“自适应进化”。

## 🏃 快速开始

### 1. 安装依赖

确保你的系统已安装 Python 3.10 ~ 3.14，并在项目根目录下安装 pandas 和 numpy 等基础库：

```bash
pip install -r requirements.txt
```

### 2. 运行数据分析排行榜

读取历史 CSV 数据进行严格校验（查重、1~49范围、合规性），并输出各项基础排行和特征分布：

```bash
python analysis.py
```

### 3. 运行滚动历史回测

使用当前配置，在 151期 ~ 191期 进行滚动前向回测，查看每次预测、累积命中率及模型相比随机盲选的性能提升：

```bash
python backtest.py
```

### 4. 开启自动策略调优（重要 ✨）

让系统自动寻找使回测命中率最高的指标和权重组合。完成后它会创建 `optimized_config.json` 供预测使用：

```bash
python backtest.py --optimize
```

### 5. 输出下一期推荐生肖预测

读取全量历史开奖数据，利用优化后的策略评分框架，计算并预测出**下一期（第192期）最值得关注的5个生肖**，同时输出完整的评分看板以及智能生成的“推荐依据”：

```bash
python predict.py
```
